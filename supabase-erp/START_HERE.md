## 🚀 Quick Setup (3 Steps)

### Step 1: Supabase Setup (5 min)
1. Go to https://supabase.com
2. Create new project
3. Copy URL and API key
4. Paste into `.env.local`

### Step 2: Database Setup (1 min)
1. Go to Supabase SQL Editor
2. Copy `DATABASE_SCHEMA.sql`
3. Paste & run in SQL Editor
4. Done!

### Step 3: Run App (1 min)
```bash
npm install
npm run dev
# Opens http://localhost:3000
```

## 🚀 Getting Started Now

### Option 1: Automated Setup (Recommended)

**Windows:**
```bash
# Double-click setup.bat
setup.bat
```

**Mac/Linux:**
```bash
chmod +x setup.sh
./setup.sh
```

### Option 2: Manual Setup
```bash
# 1. Install dependencies
npm install

# 2. Create environment file
cp .env.example .env.local

# 3. Add Supabase keys to .env.local
# Edit the file with your API credentials

# 4. Start development server
npm run dev

# 5. Open browser to http://localhost:3000
```

## 📝 Step-by-Step First Time

1. **Setup Supabase** (5 min)
   - Create account at supabase.com
   - Create new project
   - Get API keys

2. **Setup Database** (1 min)
   - Run DATABASE_SCHEMA.sql in Supabase
   - Create storage bucket

3. **Setup Frontend** (3 min)
   - npm install
   - Copy .env.example to .env.local
   - Add API keys

4. **Run App** (1 min)
   - npm run dev
   - Open http://localhost:3000

5. **Create Test User**
   - Click Sign Up
   - Fill in details
   - Click Sign Up again

6. **Add Test Data**
   - Create 3-5 products
   - Create an order
   - Create an invoice
   - Record a payment

7. **Check Dashboard**
   - Should show KPI stats
   - Charts should display
   - All data should be visible

**Total Time: ~15 minutes** ⏱️
